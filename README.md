# نظام كشف الحسابات والسندات (yasser-system)

نظام متكامل لإدارة كشوف الحسابات وسندات القبض والصرف، مصمم خصيصاً للورش ومصانع الملابس والتجار وأصحاب الأعمال، ومطابق تماماً لكشف الحساب المرفق بالصورة.

---

## 🌟 المميزات الرئيسية

1. **تصميم مطابق للصورة الأصلية تماماً**:
   - واجهة شاشة الجوال (Android App Mockup) بشريط الحالة (Status Bar 4:18، بطارية 3%، سرعة الشبكة).
   - ترويسة كشف الحساب: `كشف حساب حـ/ ياسر` مع أيقونة السجل والقائمة وخيار الرجوع.
   - فترة الكشف: `من تاريخ 18/08/2026 إلى تاريخ 21/10/2026`.
   - شارة رقم الصفحة العائمة `1/1`.
   - جدول الحسابات الأصلي بـ 8 أعمدة: `الرصيد` | `له` | `عليه` | `التفاصيل` | `نوع السند` | `التاريخ` | `الرقم` | `م`.
   - سطر الإجمالي بخلفية سيان الفاتحة المميزة (`#00e5ff`) للأرصدة والإجماليات.
   - التفقيط التلقائي باللغة العربية: `لكم : تسعة وستون ألف و مائتين وتسعون ريال`.

2. **بيانات تجريبية محملة مسبقاً (21 حركة)**:
   - تم تفريغ وتضمين كافة السندات الـ 21 الموجودة في الصورة بدقة 100% (أرقام السندات، التواريخ، تفاصيل القطع والملابس، مبالغ الدفعات والتنزيلات، وحساب الرصيد التراكمي خطوة بخطوة).
   - إجمالي دائن (له): **138,120 ريال**
   - إجمالي مدين (عليه): **68,830 ريال**
   - الرصيد الصافي المتبقي: **69,290 ريال** (لكم)

3. **لوحة تحكم إدارية شاملة**:
   - إضافة قيود وسندات قبض (له) وسندات صرف (عليه) جديدة برقم تلقائي وحاسبة كمية وسعر (مثل: 36 × 250).
   - تعديل أو حذف أي حركة مع إعادة احتساب الرصيد التراكمي والإجماليات فورياً.
   - دعم إنشاء وتبديل حسابات متعددة (عملاء، موردين، ورش، صنايعية).
   - بحث فوري في التفاصيل وتصفية حسب نوع السند والفترة الزمنية.

4. **تصدير ومشاركة وطباعة**:
   - طباعة كشف حساب معتمد A4 متوافق مع كافة الطابعات (مع إخفاء أزرار الواجهة وتجهيز الترويسة والتوقيعات).
   - مشاركة كشف الحساب مباشرة عبر WhatsApp برسالة نصية منسقة بضغطة زر واحدة.
   - تصدير كامل البيانات إلى ملف Excel (CSV).
   - حفظ تلقائي في المتصفح وملفات النظام عبر REST API (`/api/data`).

## 🚀 كيفية التشغيل محلياً

النظام يعمل الآن بالفعل على جهازك!

### الرابط المباشر في المتصفح:
- محلياً على جهازك: **[http://localhost:3001](http://localhost:3001)**
- من هاتفك الجوال أو أي جهاز على نفس شبكة الواي فاي: **[http://192.168.1.13:3001](http://192.168.1.13:3001)**

### أوامر البدء والتشغيل:

```bash
# تشغيل السيرفر في وضع التطوير
npm run dev -- -p 3001

# أو بناء وتشغيل نسخة الإنتاج
npm run build
npm run start -- -p 3001
```
